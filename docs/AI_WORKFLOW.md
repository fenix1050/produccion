# Flujo de trabajo

Antes de modificar código:

1. Leer CLAUDE.md

2. Leer AGENTS.md

3. Revisar ARCHITECTURE.md

4. Recuperar contexto usando Engram

5. Analizar el proyecto usando CodeGraph

6. Consultar el MCP si es necesario

7. Elaborar un plan

8. Esperar aprobación si el cambio es grande

9. Implementar

10. Ejecutar pruebas

11. Reunir evidencia de verificación relevante antes de entregar el cambio. Seguir los comandos y el checklist en [`docs/VERIFICATION.md`](VERIFICATION.md).

12. Actualizar documentación

13. Registrar decisiones importantes en Engram
