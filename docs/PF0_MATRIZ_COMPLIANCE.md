# PF-0 — Matriz de decisiones de Compliance para MRC

## Aprobación de cierre

El 2026-09-01, la autoridad designada del proyecto aprobó las decisiones registradas en esta matriz
para el alcance de **PF-3 de Multirriesgo Comercio (MRC)**. Por esa aprobación, dejan de ser
provisionales para dicho alcance. Esta constancia documenta una aprobación por la autoridad designada;
no alega una aprobación externa. Hogar permanece fuera de alcance y requiere su propio análisis y
habilitación.

## Objetivo

Documentar las decisiones aprobadas necesarias para habilitar la implementación de **PF-3 de
Multirriesgo Comercio (MRC)**. Este documento no habilita Hogar ni autoriza por sí solo la emisión.
